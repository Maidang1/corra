# MyGo Markdown 桌面编辑器 · 开发计划

> 基于 [MyGo](https://mygo.egoist.dev)（Go 桌面应用框架）构建，原生 UI 渲染，无 HTML / JS 前端代码。
> **v3 调整：一期即包含完整功能——Markdown 展示 + 编辑，双栏实时预览。**
> **范围：仅纯 Markdown（CommonMark + GFM），不支持 MDX。**

## 1. 背景与目标

MyGo 的核心能力：

- 用 Go 写桌面应用，窗口分两类：**Web 页面**（系统 webview）和 **Native UI**（`ui` 包纯 Go 绘制，GPU 渲染，秒开、内存低）。
- 无 cgo，单 Go 程序几 MB；跨 macOS / Windows / Linux。
- 内置桌面 API：对话框、通知、剪贴板、打印、文件监听、深浅色模式等。

本项目选择 **Native UI 路线**——不启动 webview，不用 HTML/CSS/JS，全部由 Go 客户端代码绘制界面。

**产品目标（一期完整交付）**：一个 Markdown **编辑器**，左栏编辑源码、右栏实时渲染预览，读写兼备。

## 2. 关键技术选型

| 环节 | 选型 | 理由 |
| --- | --- | --- |
| 应用框架 | MyGo（Go ≥ 1.27） | 无 cgo，交叉编译三平台 |
| Markdown 解析 | `github.com/yuin/goldmark` + GFM 扩展 | 纯 Go，CommonMark 兼容，支持表格/删除线/任务列表/脚注 |
| 代码高亮（预览区） | `github.com/alecthomas/chroma` | 纯 Go，200+ 语言主题 |
| 数学公式解析 | `github.com/FurqanSoftware/goldmark-katex`（仅用其 AST 解析） | 在 Markdown 阶段截出 `$...$`/`$$...$$`，不被 Markdown 语法干扰 |
| 数学公式渲染 | `codeberg.org/go-latex/latex` | 纯 Go 数学排版（MathJax 级别），输出字形盒后在 Native UI 画布矢量绘制；升级备选：Star-Tex |
| 图表（流程图等） | `github.com/xo/mermaid`（wazero + mermaid-rs-renderer WASM） | 纯 Go 渲染 Mermaid → SVG；覆盖流程/时序/类/状态/ER/甘特/饼图/思维导图等 13 种 |
| 图表（数据图） | `vicanso/go-charts`（SVG）或 `gonum/plot`（高质量 PNG） | 折线/柱状/饼/雷达等，围栏块内写数据，渲染结果内嵌预览区 |
| 图表（D2） | `oss.terrastruct.com/d2`（d2lib + d2svg） | D2 本身就是 Go 写的，库方式嵌入；纯 Go 布局引擎（Dagre/ELK 移植），自带主题与手绘风格 |
| 图表（ASCII） | `github.com/bep/goat` | ASCII 字符画 → SVG，Hugo 同款方案，纯 Go 零依赖 |
| 图床上传 | GitHub REST Contents API + MyGo `Fetch` 插件 | 粘贴/拖拽图片 → base64 PUT 上传到指定仓库 → 回插 CDN 链接；无 CORS、任意 Header |
| Token 存储 | MyGo secrets API（系统钥匙串） | GitHub PAT 不落明文配置 |
| 远程图片加载 | MyGo `Fetch` 插件 + 磁盘缓存 | 预览区加载 http(s) 图片，缓存到本地目录，离线显示占位 |
| 文本编辑 | MyGo Native UI 输入组件（等宽字体、多行编辑） | 无 webview 的原生编辑体验 |
| 文件监听 | MyGo `Watch` 插件 | 外部修改检测，配合编辑态冲突处理 |
| 文件打开/保存 | MyGo 对话框 + 启动参数 + 拖放 | 桌面 API 原生支持 |
| 导出 | MyGo 打印 API | 打印 / 导出 PDF |

## 3. 范围说明

- **MDX**：放弃，不做。打开时给出明确"不支持"提示。
- **原始 HTML 块**：不渲染，按代码块展示。
- **不做**：插件系统、Git 版本管理集成（图床上传已纳入一期，见功能清单）。

## 4. 应用架构

```
mdeditor/
├── main.go              // 入口：WhenReady、窗口创建、App.Run
├── app/
│   ├── state.go         // 应用状态：当前文件、内容、编辑/预览布局、主题、缩放、dirty 标记
│   ├── file.go          // 打开/保存/另存为、外部修改冲突处理、启动参数、拖放
│   └── window.go        // 窗口配置、菜单、快捷键
├── render/
│   ├── markdown.go      // goldmark AST → ui 组件树
│   ├── highlight.go     // chroma 主题/语言映射
│   └── theme.go         // 深浅色、代码主题、正文字体
├── editor/
│   ├── buffer.go        // 文本缓冲：插入/删除、undo/redo 栈
│   ├── actions.go       // 格式化动作：加粗/斜体/标题/列表/链接/代码块
│   └── search.go        // 查找 / 替换
└── ui/
    ├── document.go      // 预览视图：滚动容器 + 块级组件
    ├── blocks.go        // 标题/段落/表格/代码块/任务列表/引用/图片
    ├── editorpane.go    // 编辑区：多行编辑、等宽字体、当前行高亮
    ├── toolbar.go       // 格式化快捷栏
    └── sidebar.go       // 文件大纲（跳转）、最近文件
```

核心交互：`编辑器输入 → 防抖（300ms）→ goldmark 渲染 → 右栏刷新`；编辑态置 dirty，标题栏显示未保存标记。

## 5. 功能清单（一期完整功能）

**展示**
- GFM 全要素渲染：标题、段落、列表、任务列表、表格、引用、链接、图片、行内代码、代码块高亮、删除线、脚注、分隔线
- 数学公式：行内 `$...$` 与块级 `$$...$$`，go-latex 矢量渲染，随主题/字号缩放；不支持的宏降级为"源码 + 提示"
- Mermaid 图表：```mermaid 围栏块，流程/时序/类/状态/ER/甘特/饼图/思维导图等 13 种，SVG 内嵌
- D2 图表：```d2 围栏块，架构图/流程图，d2lib 渲染 SVG，内置主题与手绘模式
- ASCII 图表：```goat 围栏块，字符画转 SVG
- 数据图表：```chart 围栏块（YAML 数据），折线/柱状/饼/雷达等，SVG/PNG 内嵌
- 大纲导航（标题树，点击跳转）
- 字号缩放、深浅色主题（跟随系统 + 手动）
- 图片本地路径加载、点击放大
- 打印 / 导出 PDF

**编辑**
- 新建 / 打开 / 保存 / 另存为（含快捷键与未保存确认）
- 撤销 / 重做
- 查找 / 替换
- 格式化工具栏：加粗、斜体、标题级别、有序/无序列表、任务列表、引用、代码块、链接、表格插入
- 快捷键：Ctrl/Cmd+B/I/K、Ctrl/Cmd+1~6 标题、Tab 缩进
- 自动保存（可开关，默认关）

**图片与图床**
- 粘贴/拖拽图片自动上传 GitHub：剪贴板截图、拖入图片文件 → 上传 → 光标处回插 `![](cdn-url)`
- 本地图片右键"上传并替换为图床链接"
- 图床配置：GitHub token（存系统钥匙串）、目标仓库/分支、存储路径前缀（如 `images/2026/10`）、CDN 地址模板、提交信息模板
- CDN 可配置（默认 jsDelivr：`cdn.jsdelivr.net/gh/owner/repo@branch/path`），支持自定义反代地址
- 上传失败降级：回退为本地路径引用，不阻塞编辑，状态栏提示
- 文件名策略：时间戳 + 短哈希，避免冲突

**远程图片展示**
- 预览区加载 http(s) 图片：Fetch 拉取 → 磁盘缓存 → 渲染；加载失败/离线显示占位图

**文件**
- 拖放打开、文件关联、启动参数打开
- 外部修改检测：无本地改动→自动重载；有改动→弹窗让用户选"重新加载/保留我的版本/另存"

## 6. 里程碑

**M1 · 骨架跑通（1 天）**
- `mygo` 工具链、`mygo doctor` 通过；空窗口 + 基础组件冒烟测试
- 菜单与快捷键框架：打开、保存、退出

**M2 · 预览渲染（3–4 天）**
- goldmark → ui 组件树，GFM 全要素
- chroma 代码高亮（深浅色两套主题）
- 数学公式：goldmark-katex 解析 + go-latex 渲染接入画布，行内/块级、错误降级
- Mermaid：xo/mermaid 渲染 SVG 内嵌（复用 Renderer 摊薄 WASM 编译开销）
- D2：d2lib 编译 + d2svg 渲染内嵌（复用 Ruler/布局实例）
- GoAT：bep/goat 渲染 SVG 内嵌
- 数据图表：go-charts 渲染 SVG 内嵌
- 滚动、缩放、主题切换

**M3 · 编辑能力（4–5 天）**
- 编辑区组件 + 文本缓冲 + undo/redo
- 打开/保存/另存为 + dirty 管理 + 关闭确认
- 格式化动作与工具栏、快捷键
- 查找/替换
- 双栏布局：编辑、预览、双栏三种模式切换；预览防抖刷新
- 剪贴板/拖拽图片接收 + GitHub 上传链路（token 配置、失败降级）

**M4 · 阅读与文件体验（2–3 天）**
- 大纲导航、最近文件、拖放、文件关联
- 外部修改冲突处理（Watch 插件）
- 打印/导出 PDF、图片放大查看

**M5 · 打包分发（1–2 天）**
- 三平台构建（图标、版本信息、安装包/dmg）
- GitHub Actions 打 tag 自动发布
- README 使用说明

总工作量约 **11–15 天**。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| Native UI 文本编辑组件能力（多行编辑、选区、撤销粒度）可能弱于预期 | M3 第一周先做编辑区技术验证（spike）；若原生组件不足，降级方案是自绘文本视图（纯 Go 可控但工期 +3 天） |
| 大文档实时预览性能 | 防抖 + 仅重渲染变更部分；仍不足则预览改手动刷新按钮 |
| Native UI 富排版弱于 webview | 图片混排降级；复杂排版给出提示 |
| 外部修改与本地编辑冲突 | 明确的三选一弹窗，不静默覆盖 |
| go-latex 宏覆盖不全（生僻宏包、\newcommand） | 降级为"源码 + 错误提示"；需求升级时切 Star-Tex 引擎 |
| Mermaid WASM 版与官方非像素级一致（YAML front matter / init 指令受限） | README 写明边界；重渲染复用 Renderer 实例，避免重复编译开销 |
| 数据图表配置语法需自定义（无统一标准） | 采用 ```chart YAML 方言，文档给出示例；失败降级为源码块 |
| d2 依赖树较重，安装包体积增大 | 仅编译期依赖，按需初始化；实测后如超标再评估裁剪 |
| Linux 依赖 GTK3 | CI 覆盖；README 写依赖 |
| GitHub token 泄露风险 | 只存系统钥匙串（secrets API），配置文件不落明文；支持 token 随时更换 |
| CDN 国内可达性（jsDelivr/raw 域名时有波动） | CDN 地址做成可配置项，默认 jsDelivr，支持自定义反代/镜像地址 |
| GitHub API 速率与单文件限制（认证 5000 次/时、单文件 100MB） | 个人使用场景远低于上限；超大图片上传前本地提示 |
| 网络不可用时上传失败 | 降级为本地路径引用并状态栏提示，内容不丢 |

## 8. 验收标准

1. 双栏模式下左侧编辑、右侧 300ms 内实时渲染，GFM 全要素正确；
2. 行内/块级数学公式正确渲染，深浅色下对比度正常，不支持的宏有降级提示；
3. mermaid/d2/goat/chart 四类围栏块渲染为图表，语法错误时降级为源码 + 提示；
4. 编辑/预览/双栏三种模式可切换；
5. 打开、编辑、保存全流程完整，异常关闭不丢内容（关闭前确认）；
6. 撤销/重做、查找/替换、格式化工具栏全部可用；
7. 外部修改文件有三选一冲突处理；
8. 打印/导出 PDF 可用；
9. 三平台可执行包构建成功，全程无 HTML/JS 前端代码；
10. 打开 MDX 文件给出明确"不支持"提示；
11. 粘贴/拖拽图片自动上传 GitHub 并回插链接，token 不落明文，断网降级不丢内容；
12. 预览区远程图片可加载并有缓存，离线显示占位。
