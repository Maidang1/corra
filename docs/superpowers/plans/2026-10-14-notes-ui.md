## Review additions

app/file.go dispatches watcher snapshots on the UI thread and rejects old/stopped watchers. Flush returns a boolean; failure aborts transitions and close. Save As syncs the buffer without requiring the original path to be writable. app/save.go uses atomic replacement. Preview nested checkboxes flip only their original source marker. Relative attachments are rebased on note move/delete/restore. Async image publication is synchronized.
