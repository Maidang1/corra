## 已知限制汇总（框架层）

1. **无 WebView**：任意 CSS 主题和交互式 iframe 的完整兼容与当前架构约束存在冲突，尚未实现。MathJax 已通过离线 Goja 排版接入，不依赖 WebView；本地视频的原生播放仍待实现。
2. **尚未接入的能力**：MyGo 文本对象可用于预览里的行内公式图，仍需实现布局和绘制；PDF 书签尚未接入 gpdf。Windows/Linux 不在本次 macOS 原生目标范围内。
3. **表格拖拽调宽/拖拽重排行列**：尚未实现拖拽手柄；macOS 原生右键菜单现已支持行列增删、移动和对齐，Cmd+Enter 插行，Cmd+Shift+Backspace 删正文行，支持矩形 TSV 粘贴。

## 2026-10-15 macOS 原生编辑升级

本轮继续使用 AppKit，不引入 WebView。新增原生嵌套列表、独立编号与
有序任务续项、表格结构菜单与矩形粘贴、代码块多行缩进、行内扩展格式
实时输入规则，以及带标题链接/已解析引用链接的富文本编辑。

此表中的历史“已有/新增”不代表全部通过交互验收。完整 Typora 编辑能力
仍未达成：复杂混合容器、数学偏好与导出一致性、HTML/
媒体嵌入、表格/图片拖拽交互，以及表格拖拽调宽/行列拖拽手柄、可编辑 YAML 元数据、
本地视频原生播放、应用内版本恢复、PDF 书签、原生字体/行高/宽度偏好、
Touch Bar 等仍需继续实现；已支持的行内
格式和验证边界见上表。脚注的就地编辑已实现并通过 20 项原生回归，
但真实中文输入法候选交互与大文档输入性能尚未人工验收。
原生编辑的引用链接在未编辑时保持原文；编辑所在段落后可规范化为携带
相同地址和标题的行内链接，引用定义保持原样。
