# 编辑器交互打磨总结

本文总结近期 Corra 富文本编辑器的一系列交互与界面打磨：补齐 Notion / Typora / Obsidian 等编辑器常见的快捷操作，并保持原生面板的视觉与明暗主题一致。

## 背景

- Corra 是 Go + MyGo 的原生桌面 Markdown 编辑器，富文本编辑区由 macOS AppKit `NSTextView` 经 cgo 承载（`nativerich/`）。
- 目标：在不引入 WebView 的前提下，把高频编辑动作（插入块、改格式、管理图片/表格、跳转文档）做成**就地、键盘可达、可发现**的交互。
- 约束：浮层不能抢走文本焦点；面板必须跟随明暗主题；所有交互需要可回归测试。

## 功能清单

### 输入与命令面板

| 功能 | 触发 | 说明 |
| --- | --- | --- |
| 斜杠菜单 | 空行输入 `/` | 23 个块类型，分组、过滤高亮、↑↓ 选择、回车应用、Esc 关闭 |
| 表情选择器 | 词首输入 `:` | 约 120 个精选 shortcode，`:smi` → 😄，过滤、键盘/点击插入，替换整段查询 |
| 文档链接补全 | 输入 `[[` | 检索文档库（标题/路径），显示相对路径，插入可点击链接 `[标题](相对路径.md)` |
| 标题锚点 | 输入 `[[#` | 列出当前文档标题，插入 `[标题](#anchor)`，中文锚点保留 |
| 快速打开 | `⌘⇧P` | 按标题/文件夹/路径筛选；空查询分「最近打开 / 全部文档」 |
| 命令面板 | `⌘⇧P` 后输入 `>` | 17 个动作（新建、插入、导出、主题、设置等）附快捷键提示，↑↓ 选择、回车执行 |

### 富文本编辑交互

- **选区格式浮动条**：加粗、斜体、下划线、删除线、行内代码、高亮、链接、清除格式；当前状态高亮，位于选区上方/下方。
- **块操作**：块手柄菜单、`⌘⇧↑/↓` 移动、`⌘D` 复制、`⌘⇧⌫` 删除；块可整体拖动排序，移动/复制/删除以块为单位。
- **代码块**：悬停右上角复制按钮；语言标签下拉（14 种语言 + 自定义）；全局行号开关。
- **图片**：悬停尺寸条（原图 / 25% / 50% / 75% / 100%）、替换、复制、删除；尺寸写入 Markdown 后缀；替换保留替代文本/标题/尺寸，文档目录内文件写相对路径。悬停控件的点击已在 `mouseDown` 真实接线（此前只经测试桥可达），图片 pill、表格加行/加列、代码语言标签的物理点击均走同一分发。
- **表格**：悬停表格右侧「+」加列、下方「+」加行；右键支持行列插入、删除、移动与对齐。
- **脚注**：悬停引用立即浮出定义卡片（标题 + 正文，自动换行与截断），无需等待系统 tooltip。
- **目录/标题**：文档内 `#` 锚点跳转、脚注引用与定义互相跳转。
- **脚注返回**：`⌘⌥↓`/`⌘⌥↑` 跳转引用与定义时记录起点，`⌘⌥←` 精确回到跳转前位置（同一脚注多处引用时不会错回第一处），再按一次往返切换；右键菜单提供「返回跳转前位置」，命令面板有「返回脚注跳转位置」；切换文档自动清除返回点。

- **导出面板**：头部「共享与导出」菜单与命令面板打开格式卡片模态——PDF、HTML 各一张说明卡片，pandoc 六种格式各一张（未安装 pandoc 时禁用并给出安装提示）；点击卡片按钮先关模态再弹出系统保存面板，避免对话框叠在模态上。

### 状态与导航

- **文档统计**：点击状态栏字数，展开一行统计胶囊——字数、字符、行数、标题、链接、图片、任务、代码块、阅读时间；统计跳过围栏代码。
- **侧栏**：收起/展开过渡、折叠态头部、最近文档列表。
- **侧栏键盘导航**：文档行聚焦后 ↑↓ 循环遍历并打开文档（焦点随行移动，连续按键不走失）；搜索框聚焦时 ↑↓ 同样移动选中但光标留在框内可继续输入，回车把焦点交给编辑器。快捷键只在侧栏子树聚焦时生效，不会从编辑器抢键。
- **主题**：全部原生面板与浮动控件跟随明暗主题，强调色/弱化色统一。

## 架构与关键决策

1. **编辑器内浮层统一用无焦点子 `NSPanel`**（`canBecomeKey = NO`）：点击面板不夺走文本焦点，失焦、滚动、切换文档、输入变化时自动关闭。
2. **视图类放文件作用域头文件，编辑器方法 include 进 `@implementation CREditor`**：既能访问 ivar，又避免 Objective-C 分类不能声明 ivar 的限制。
3. **Go 与 ObjC 的边界**：桥函数 + JSON 状态（面板状态、输入、截图），编辑器回调（图片保存、链接候选）通过 `cgo.Handle` 反向调用 Go。
4. **绘制顺序**：文本容器之外的悬停控件（左侧块手柄、表格加行/加列按钮）在 `[super drawRect:]` **之前**绘制，否则会被 NSTextView 裁剪；覆盖在字形上的控件（图片尺寸条、拖动插入线）在之后绘制。
5. **输入触发规则**：插入、删除、选区变化统一走查询刷新；代码块、表格、公式、脚注定义等受保护块不触发；斜杠/表情/链接面板互斥。
6. **确定性测试**：测试不走阻塞式原生菜单，而是直接调用测试桥（hover/choose/drag）；`nativeTestMain` 内不使用 `t.Fatalf`，避免 Goexit 跳过主线程返回导致死锁。

## 验证

- `go test ./...` 全量通过，`go vet ./...` 无告警。
- 原生测试覆盖：斜杠菜单、格式条、块操作、脚注卡片、表情面板、链接补全、标题锚点、表格控件、图片操作、拖动排序。
- Go 单测覆盖：链接候选（相对路径/排除自身/过滤）、文档统计扫描、快速打开全流程（过滤、命令、最近分组、↑↓）。
- 视觉检查：离屏截图脚本，按需设置环境变量生成 PNG：
  - `CORRA_SLASH_SHOT`、`CORRA_FORMAT_BAR_SHOT`、`CORRA_HOVER_SHOT`
  - `CORRA_EMOJI_SHOT`、`CORRA_LINK_SHOT`、`CORRA_TABLE_SHOT`
  - `CORRA_SCREENSHOTS`（快速打开、命令面板、文档统计等外壳截图）
  - 产物写入 `.cache/`（已 gitignore），便于逐轮目检。
